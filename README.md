# Anh's Sanctuary

Portfolio of Anh Vu, product designer. A cozy pixel room you can walk around with your keyboard (1–5, L for lights, M to mute) or your mouse.

Static site: plain HTML, CSS and JS, no build step. Hosted on Cloudflare Pages.

- `index.html` – the whole site
- `work/` – case study and side quest media
- `logos/` – toolkit logos
- `room-*.webp`, `tree-*.webp`, `cloud-*.webp` – the room art (drawn in Figma)
